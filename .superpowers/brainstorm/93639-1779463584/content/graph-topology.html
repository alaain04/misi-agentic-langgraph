Section 1 — New Graph Topology

How the LangGraph pipeline is restructured around skills and evidence

Main Investigation Graph (new)
START
│
▼
[ discovery ] ← unchanged: clone → inspect → SBOM → summary
│
▼
[ investigation_planner ] ← NEW: LLM reads concern + SBOM → generates InvestigationPlan
│ Plan = { hypotheses[], skill_assignments{dep→skills[]} }
│
▼ interrupt() ← HITL gate 1: user approves plan
│
▼
[ skill_dispatcher ] ← NEW: fans out Send() per (dep, skill) pair
│
├─ Send(dep_A, VulnerabilitySkill) ──→ [ skill_executor ]
├─ Send(dep_A, MaintainerTrustSkill) ─→ [ skill_executor ]
├─ Send(dep_B, SupplyChainSkill) ────→ [ skill_executor ]
├─ Send(dep_B, BlastRadiusSkill) ────→ [ skill_executor ]
└─ Send(direct, ReachabilitySkill) ──→ [ skill_executor ]
│
▼
each executor writes Evidence[] to shared state
│
▼
[ evidence_collector ] ← waits for all skill_executors (replaces stage_advance)
│
▼
[ evidence_correlator ] ← NEW: replaces cross_analyzer
│ correlates signals, detects contradictions,
│ scores confidence, produces RiskFindings[]
│
▼
[ finding_reviewer ] ← NEW: replaces report_reviewer
│ LLM validates findings for coherence + coverage
│ loops back to correlator if weak
│
├─ high_severity_found? ──→ interrupt() ← HITL gate 2: human reviews findings
│
▼
[ report_builder ] ← deterministic: assembles final structured report
│
▼
END

What changed vs. current graph

Current node New equivalent Key difference
orchestrator + planner investigation_planner outputs InvestigationPlan with hypotheses, not just subgraph names
task_dispatcher + execution_planner skill_dispatcher fans out per (dep, skill) pair, not per subgraph type
execute_plan (invokes full subgraph) skill_executor runs a single skill protocol, writes typed Evidence objects
stage_advance evidence_collector same fan-in pattern, but now accumulates Evidence[], not result_ids
cross_analyzer (dict merge) evidence_correlator LLM-driven correlation with confidence scoring and contradiction detection
report_reviewer (max 2 loops) finding_reviewer + HITL gate 2 structured review criteria + human gate on high-severity findings

Key invariant: The graph topology is stable — only 6 backbone nodes. What changes per investigation is the contents of the skill_plan (which skills run for which deps), not the graph shape. Adding a new skill requires zero graph changes.
